# نور القرآن — Noor Quran

تطبيق قرآن لأندرويد 16 فما فوق (minSdk 36)، مبني بـ Kotlin وJetpack Compose وMaterial 3.

## المزايا
- المصحف كاملاً بالرسم العثماني، 114 سورة و30 جزءاً، مقسماً بحسب صفحات المصحف، يعمل بلا إنترنت بعد أول تحميل.
- تلاوة آية بآية مع تظليل الآية الجارية وتتبعها تلقائياً، و13 قارئاً.
- تشغيل في الخلفية مع إشعار وأزرار شاشة القفل (Media3 MediaSession).
- تخزين مؤقت للتلاوات (300MB) فيعاد تشغيل ما سُمع دون إنترنت.
- سرعة تشغيل، تكرار الآية، مؤقت نوم.
- بحث بالكلمة غير حساس للتشكيل، وبحث بأسماء السور.
- علامات مرجعية، ومتابعة القراءة من آخر موضع.
- التفسير الميسر عند الضغط على الآية، ونسخ ومشاركة الآية.
- مظهر فاتح/داكن/النظام، وألوان Material You، وحجم خط قابل للضبط.
- واجهة عربية RTL مع ترجمة إنجليزية، وأيقونة تكيفية مع Monochrome.

## التشغيل
1. افتح المجلد في Android Studio (Narwhal أو أحدث) وانتظر مزامنة Gradle.
2. شغّل على جهاز أو محاكي بأندرويد 16 (API 36).
3. (اختياري) ضع خط المصحف في `app/src/main/assets/fonts/quran.ttf`.

أول تشغيل يحتاج إنترنت لتحميل النص مرة واحدة.

## البنية
- `data/` Room (السور، الآيات، العلامات) + DataStore + OkHttp + المستودع
- `player/` PlaybackService (ExoPlayer + MediaSession) وPlayerController
- `ui/` شاشات Compose: الرئيسية، القراءة، البحث، العلامات، الإعدادات

## المصادر
النص والتفسير: api.alquran.cloud — التلاوات: everyayah.com
تحقق من شروط استخدام هذه المصادر قبل النشر في المتجر.
